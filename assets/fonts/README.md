# خط PDF العربي

يحتوي هذا المجلد على خط **Amiri** (نسخة Regular وBold حقيقيتان
منفصلتان) لاستخدامهما في تصدير التقارير كملفات PDF
(`lib/services/export_service.dart`):

- `arabic_regular.ttf`
- `arabic_bold.ttf`
- `OFL.txt` — رخصة SIL Open Font License 1.1 (مجاني للاستخدام
  والتوزيع مع التطبيق، بما في ذلك تضمينه داخل APK).

المصدر: مستودع Google Fonts الرسمي
(`github.com/google/fonts/tree/main/ofl/amiri`)، وهو نفس الخط
المستخدم في مواقع عربية أكاديمية ونشرية كثيرة لجودته في الطباعة.

لا حاجة لأي إجراء إضافي — التطبيق يحمّل هذين الملفين تلقائيًا عند
أول تصدير PDF عبر `rootBundle`، ويعملان بدون إنترنت بالكامل لأنهما
مضمَّنان داخل التطبيق نفسه (assets) وليسا مُنزَّلين وقت التشغيل.
